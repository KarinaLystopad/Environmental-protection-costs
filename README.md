# Аналіз витрат на охорону навколишнього природного середовища в Україні

## Тема
Аналіз витрат на охорону навколишнього природного середовища в Україні.  
Дані зібрані з офіційного сайту Державної служби статистики України ([stat.gov.ua](https://stat.gov.ua)) та охоплюють регіональний розріз (області та м. Київ).

## Актуальність
Охорона довкілля є критично важливою сферою для сталого розвитку країни.  
Фінансування природоохоронних заходів напряму впливає на якість життя населення, стан водних ресурсів, повітря, утилізацію відходів та розвиток «зеленої» економіки.  

Аналіз витрат дозволяє:
- Виявити регіональні дисбаланси у фінансуванні.  
- Оцінити пріоритети держави та бізнесу у сфері екології.  
- Сформувати рекомендації для різних рівнів — від окремих громадян до державних органів.  

## Мета проєкту
- Провести очищення та структурування даних.  
- Виконати описову статистику та базовий аналіз (динаміка, кореляції, візуалізації).  
- Сформувати висновки щодо стану фінансування природоохоронних заходів.  
- Надати рекомендації для подальших дій на рівні громадян, організацій та держави.
