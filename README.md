# 📊 Аналіз витрат на природоохоронну діяльність в Україні (2021–2025)

## 🔹 Технічне завдання

1. [Збір даних](ca://s?q=Збір_даних_з_stat.gov.ua) з офіційного сайту [stat.gov.ua](https://stat.gov.ua/)  
2. [Очищення](ca://s?q=Очищення_даних_у_Python) та підготовка у форматі CSV  
3. [Аналіз](ca://s?q=Аналіз_екологічних_витрат) у Python (описова статистика, кореляції, візуалізації)  
4. [Візуалізація](ca://s?q=Візуалізація_у_Tableau) у Tableau (дашборд для презентації)  
5. [Висновки та рекомендації](ca://s?q=Висновки_та_рекомендації_по_екологічних_витратах) для різних рівнів (індивідуальний, організаційний, державний).

---

## 🔹 Дані
- Джерело: офіційна статистика України (stat.gov.ua)  
- Період: 2021–2025  
- Формат: CSV після очищення  
- Основні поля:
  - `Рік`
  - `Територіальний розріз`
  - `Напрям природоохоронної діяльності`
  - `Показник`
  - `Витрати`

---

- Менші напрями: біорізноманіття, наукові дослідження, шумовий вплив.

## 🔹 Висновки
- Витрати нестабільні, але загалом відновлюються після падіння у 2022.  
- Є сильна концентрація коштів у кількох регіонах.  
- Основні напрями — відходи та вода, що відображає ключові екологічні проблеми.  
- Деякі регіони недофінансовані, що може бути ризиком для екологічної політики.

## 🔹 Рекомендації
- **Для окремої людини:** підтримувати локальні екологічні ініціативи.  
- **Для організацій:** інвестувати у напрями з низьким фінансуванням (біорізноманіття, наукові дослідження).  
- **Для держави:** збалансувати фінансування між регіонами, посилити підтримку недофінансованих сфер.
